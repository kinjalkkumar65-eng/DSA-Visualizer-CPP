# DSA Visualizer Project

An interactive console-based **DSA Visualizer** built using **C++** that demonstrates how popular sorting and searching algorithms work step-by-step using ASCII visualization.

---

## Features

- Bubble Sort Visualization
- Selection Sort Visualization
- Insertion Sort Visualization
- Linear Search
- Binary Search
- Random Array Generation
- ASCII Bar Visualization
- Comparison Counter
- Swap Counter
- Menu-Driven Interface

---

## Technologies Used

- C++
- STL (Standard Template Library)
- Object-Oriented Programming (OOP)

### Compile
