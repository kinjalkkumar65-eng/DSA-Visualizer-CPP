# DSA Visualizer Project

## 📌 Description

This is a console-based DSA Visualizer developed using C++.

The project demonstrates the working of popular sorting and searching algorithms with step-by-step execution visualization.

---

# 🚀 Algorithms Implemented

## Sorting Algorithms
- Bubble Sort
- Selection Sort
- Insertion Sort

## Searching Algorithms
- Linear Search
- Binary Search

---

# ✨ Features

- Step-by-step visualization
- Random array generation
- ASCII bar visualization
- Comparison counter
- Swap counter
- Menu-driven interface
- User-friendly console output

---

# 🛠 Technologies Used

- C++
- STL
- OOP Concepts
